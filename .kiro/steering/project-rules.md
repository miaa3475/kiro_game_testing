# 專案規則

## 技術限制

- 使用**純 HTML／CSS／JavaScript**，不引入任何框架
- 不使用 Node.js、Vite、打包工具或任何外部 API
- 所有相依資源須本地化，不依賴 CDN 以外的遠端服務

## 目錄結構

- 網站所有檔案放在 `docs/` 目錄下
- 根目錄僅存放設定檔（如 `.kiro/`、`.git/`、`README.md` 等）

## 資料與語言

- 使用**模擬資料**（mock data），不串接真實後端或資料庫
- 介面語言使用**繁體中文**
- 版面須為**響應式設計**（RWD），支援桌機與行動裝置

## 發布設定

- 透過 **GitHub Pages** 發布，來源設定為 `main` 分支的 `docs/` 目錄
- 確保 `docs/index.html` 為網站入口點

## 開發注意事項

- 目前階段**不建立網站程式**，僅完成設定
- 日後新增功能請遵守上述技術限制，保持零外部依賴原則
